Greengram Pest Image Dataset
============================

10 pest folders, 4 images per folder (40 JPG images total).
The images are AI-generated reference images and should be treated as visual training/reference material, not as taxonomic specimen photography.

Folders:
- Lab_lab_bug: Coptosoma cribraria / Megacopta cribraria
- Bean_aphid: Aphis craccivora
- Leaf_hopper: Empoasca kerri
- White_fly: Bemisia tabaci
- Eriophyid_mite: Aceria cajani
- Leaf_webber: Eucosma critica
- Leaf_roller: Caloptilia soyella
- Lab_lab_leaf_miner: Cyphosticha coerulea
- Blister_beetle: Mylabris phalerata
- Flower_webber: Eublemma hemirrhoda
